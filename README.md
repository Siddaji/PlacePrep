# 🚀 PlacePrep

PlacePrep is a placement preparation platform that helps students prepare for technical interviews by organizing important **DSA problems**, **Core CS Subjects**, and **System Design resources** in one place.

## ✨ Features

- 📚 Curated DSA problem list
- 🏢 Company-wise interview preparation
- 🎯 Placement-focused questions
- 🖥️ System Design learning resources
- 📖 Core CS Subjects
- ⚡ Fast and responsive UI
- 🔗 REST API backend using Express.js

---

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/PlacePrep.git
```

```bash
cd PlacePrep
```

---

### 2. Install Frontend

```bash
cd frontend
npm install
```

Start the frontend

```bash
npm run dev
```

---

### 3. Install Backend

```bash
cd ../backend
npm install
```

Start the backend

```bash
npm run dev
```

or

```bash
npm start
```

## 🌐 API Endpoints

| Endpoint | Description |
|----------|-------------|
| `/api/problems` | Fetch DSA problems |
| `/api/system-design` | Fetch System Design resources |
| `/api/subjects` | Fetch Core CS subjects |
